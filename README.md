# SitePulse Iraq

**Bilingual field reporting for small contractors, maintenance teams, supervisors and inspectors.**

Live MVP: https://sitepulse-iraq.netlify.app

## Current MVP — v0.2

- Projects and active-project selection
- Daily Site Reports
- Punch List tracking
- Open / In Progress / Closed status
- Priority, discipline, area and assignee fields
- Photo attachment
- Company branding and logo
- Printable / Save-as-PDF punch report
- Arabic / English interface
- Local backup and restore
- Offline-first browser storage

## Current limitation

This validation version stores data in the user's browser using `localStorage`. Different devices do **not** share the same data yet.

## Product direction

The next commercial stage is planned around:

- User login
- Cloud database
- Company workspaces
- Shared projects
- Team permissions
- Before / after photos
- Signatures
- Improved PDF reports
- Excel export
- Subscription plans

## Validation goal

Before adding expensive infrastructure, test the workflow with real field users and confirm that SitePulse saves time compared with paper, Excel and scattered photos/messages.
